# M10.1 - questions for the Table (ADR-0011 Amendment B)

Where B-2's shape and an entry of the watch do not meet, the builder did the nearest thing the
amendment's words allow and asks here. Nothing below is answered locally.

## Q1 - a tree event has no summary
A tree row of state() holds no sentence of its own, and B-4 forbids a new one. The tree event is
built without `summary` (its subject, evidence and knocked say it). Should a tree event carry the
report's tree line as its summary (that text is built in host.py's report, out of M10.1's scope)?

## Q2 - a source finding "pending at exit"
B-2 lists a source finding's state as settled | history | judged on another tree | noted. The entry
also holds host.py's PENDING_EXIT ("pending at exit": its post never came; silence, an alarm of the
tree). The module keeps that word as the state (dropping it would hide an alarm) and check() accepts
it. Is it a fifth state, or should it map to one of the four? Also: the precedence used is
judged_on, then history, then benign_note (noted), then the entry's own state; is that the order?

## Q3 - knocked.event is held only by a knock row
A finding, a source finding, a hole and a tree hold only the knock's status (`notice`, `knocked`),
not the knock's event name, so their `knocked` is {status} and only a knock event has
{status, event}. A finding's knock event is its rule id in host.py's code, but the entry does not
say so, and B-2 says never guessed. Should M10.2 have the watch record the event on the entry?

## Q4 - subject.named has two types
A finding of a tree holds its named word ("named", "unknown" ...); a tree row holds `named` as a
boolean. The module emits each as the entry holds it, and EVENT.md says so. Should one of them
change (the tree row's word is built in host.py, out of scope)?

## Q5 - evidence.record is never emitted
No entry of the watch holds a field named `record` or plainly meaning it (a finding and a dark note
hold a `sample`, which the builder could not settle as B-2's record inside M10.1). The key is named in
EVENT.md and in the module's key list, and is emitted by no kind yet. Which entry field is `record`?

## Q6 - the time of an event
B-1 says the caller gives the time. `event.ledger` uses an entry's own `at` where it holds one (a
finding, a source finding, a hole, a knock, a dark note: when Raqib said it), the state's `started`
for the watch's start, and the caller's time for the rest (a tree, a plain note, the heartbeat, the
end). Is that what "when Raqib said it" means for M10.2?
