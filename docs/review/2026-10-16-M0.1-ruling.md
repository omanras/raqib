## Findings (suspicion only; none blocks landing)
- F1 **Pairing ambiguity** (capture.py build_record): a post pairs with the
  oldest open pre having the same (tool, input_sha256). Two identical commands
  in flight can cross-pair; an `updatedInput` rewrite leaves a pre orphaned.
  Resolved by Amendment A-2 (tool_use_id primary key). → task M0.1b.
- F2 **O(n) log re-read per hook** (session_state): every hook reads the whole
  log under flock. Correct, but cost grows with the log. Recorded as
  KNOWN-DEBT §1; revisit when logs exceed ~50k lines or hooks exceed 50 ms.
- F3 **Session events emit SILENCE noise** until M0.3 wires them: expected,
  harmless, documented in the questions file. Amendment A-3 fixes shape.
- F4 **pytest not in base image**: gate would be red on a fresh cloud
  session. Amendment A-7 (gate installs pytest if missing).
- F5 **stderr silence line carries log path and exception text**: acceptable
  (stderr is Claude Code's hook log, not the trace), noted for the threat
  model in M3.2.
