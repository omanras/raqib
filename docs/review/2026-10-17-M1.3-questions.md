# M1.3 example household - design questions and one scope deviation

## Scope deviation (disclosed)

`tests/test_cli.py` is outside the M1.3 scope, yet one token in it was
changed: the tuple `("review", "init")` in
`test_commands_not_yet_available_are_usage_errors` became `("review",)`.

Why: the builder itself wrote that assertion in M1.2 ("init is not
available yet"), and M1.3 E4 requires `init` to exist. With the test
untouched the gate is red and the task cannot land; the commander's
instructions reserve STOP for a conflict with the constitution or an
irreversible change, neither of which this is; and wording the `init`
refusal so that it happens to contain "not available yet" would have been
a hack. The change is the smallest that resolves the builder's own stale
assertion; nothing else outside scope was touched. The commander may
revert it and decide otherwise. Lesson for the builder: never assert
that a planned feature is absent.

## Readings taken

1. **The kill is closed, the position is kept.** The handoff says the
   kill crossed in 2025-11 and was closed by a decision dated 2025-12-05
   and that everything else holds at 2026-09-30. Had the pilot been sold,
   the broker account would read 0 on 2025-12-31 and the rolling-window
   drawdown would cross again after the closing decision (kill again). So
   the story is: no new money, position kept, value recovers. The README
   says so.

2. **Equities band 2%..30%.** With a 500 OMR pilot against 4000-11000
   OMR of savings the equity share runs from about 10% down to 4.75%, so
   the band of the ADR example (20..50) would breach everywhere; the
   household declares 2..30 instead.

3. **Second routine is rent** (`category: housing, min_amount: 250`,
   monthly) rather than a quarterly one; the quarterly-over-month paths
   are already tested in M1.2 and a monthly rent keeps the example story
   simple. The missing routine of 2026-03 is the savings transfer only.

4. **`init` copies every regular file in `examples/`**, README.md
   included, refuses with exit 2 when any of them already exists in the
   target (and writes nothing), creates the target directory when needed,
   and exits 3 when the examples directory cannot be found next to the
   package (an installed-elsewhere layout, not supported in v0.1).

5. **The generator verifies itself.** `tools/make_example.py` runs
   `qayd check` over what it wrote and asserts the planted verdict set
   for eight as-of dates before it reports success, so the example can
   never drift from its README. It uses integer baisa and cents and
   formats text; no float anywhere.

6. **Citations on a holding `months_of` floor are long** (every expense
   row of the trailing twelve months). A4 asks for them; the text output
   prints them all. Abbreviating holds in text (keeping JSON complete)
   would need `report.py`, which is outside this task's scope: left as an
   open item for the commander.
