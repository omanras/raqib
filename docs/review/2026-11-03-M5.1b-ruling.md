# M5.1b ruling (the Table, 2026-11-03) - on the STOP 4531e1f (Q-1..Q-5)

The STOP was right: E3 as written ("partial, never silence") misapplied A3
to a signature. A signature that does not match is a judged negative, on
Windows as on POSIX; A3 governs capture gaps and unplaceable values, not
the absence of a dangerous root. Rulings (ADR-0001 Amendment C):

- C-1 (Q-2, Q-1 void) A Windows cwd outside SCOPE-CWD-ROOT's list is a
  judged negative. No new engine construct. The partial note text stays.
  The Windows branch of the list: `X:\`, `X:\Users`, `X:\Users\<name>`,
  `X:\Windows`, `X:\Windows\Temp`, `X:\Temp`, `X:\Program Files`,
  `X:\Program Files (x86)`, `X:\ProgramData`,
  `X:\Users\<name>\AppData\Local\Temp`, and a UNC share root
  `\\server\share`; any case; trailing `\`, `/` or `\.` allowed. Known holes
  named in the description: `X:\Users\Public`, OneDrive-redirected homes,
  junctions, subst drives. So every Windows session from a project directory
  is a judged negative (ADR-0005 C-6 holds), test_watch b6 runs on Windows,
  and the `C:\` negative is measured.
- C-2 (Q-3) Under a Windows cwd: a rooted path with no drive (`\Users\x`)
  and a drive-relative path (`C:x`) cannot be placed -> partial (the note's
  text "a path cannot be placed" is exact). A POSIX-absolute path or the
  MSYS form `/c/...` is outside a Windows project and fires SCOPE-PATH;
  the MSYS form is recorded as a known false-positive source in the rule's
  description (Git Bash on Windows), with one fixture showing it.
- C-3 (Q-4) `--root` keeps `os.path.abspath` semantics of the host: on
  Windows `/x` means `<cwd drive>:\x`. Recorded in cli.py's help text.
- C-4 (Q-5) Scope widened to README.md:17 (one line), docs/THREAT_MODEL.md
  section 7 (platform lines), tests/test_docs.py.
- C-5 engine.py imports no ntpath (gate PREIMPORT); the normaliser is
  hand-written; UNC is recognised by backslashes only so POSIX `//x` keeps
  collapsing to `/x`.
- C-6 D-8: every added behaviour has a test; the four YAMLs list the new
  fixtures; `check-rules` before/after identical for POSIX fixtures.
- Ledger, Table: E3's "partial never silence" was wrong (a judged negative
  is not silence); same class as the SILENCE-EMPTY "medium" error.
