## F1 fixed (commit `landed: M2.1 REDO backend failures are error lines`)

- `raqib/suspect/core.run` turns any exception from a backend into an error
  line, `"<backend> failed: <Type>: <message>"`. A backend can no longer end
  a run without a record.
- The anthropic backend maps three more cases to BackendErrors:
  - the SDK's missing-credentials TypeError, reported as `anthropic: no
    credentials (set ANTHROPIC_API_KEY or ...)`;
  - any other SDK exception;
  - a failure while creating the client.
- **The real run, repeated:** `suspect <quickstart trace> --backend
  anthropic -o s.jsonl`, with no key, on anthropic SDK 1.15.0.
  - It printed `1 windows judged ...: 0 raised, 1 errors`.
  - It exited 1.
  - It wrote one error line, `anthropic: no credentials (set
    ANTHROPIC_API_KEY or `ant auth login`)`, and the run record.
