- G-1 (R3, Q-1, A6) The benign set must hold the realistic case: the
  Windows desktop fixture gets a command running in VS Code's terminal
  (Code.exe --type=ptyHost -> powershell -> command), and a Linux desktop
  with a JetBrains IDE under ~/.local whose terminal runs make -> cc. The
  class narrows so that these measure 0 and Kimi still fires:
  (a) the act-root's own parent is a shell or a terminal host (cmd,
  powershell, pwsh, bash, sh, zsh, conhost, mintty, kitty, wezterm,
  alacritty, gnome-terminal-server, tmux, screen); a root launched by a
  GUI shell (explorer, a desktop session) is not an act-root;
  (b) a process whose argv carries `--type=` (Electron/Chromium helper)
  is neither a root nor a hop;
  (c) the chain is shell -> ... -> command where the first hop below the
  root is a shell (R-7 kept) and the command is not under the root's own
  directory tree.
  Both (a) and (b) are listed as evasions (launch from a GUI launcher;
  strip --type). The README fp paragraph states the set's contents.
