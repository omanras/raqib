  the old bytes are a prefix plus an insertion.
- C-2 `image` and `parent_image` of a net line are read from `_event_fields` of that process's own event 1 (the
  one gate; no second normaliser). A start keyed by ProcessGuid is taken from the whole pass (AN-2: a mixed clock
  may sort a connection before its start), one keyed by a pid alone as the walk meets it. A bounded follow keeps the
  starts it read in its tree (`tree["starts"]`), so a later pass's connection names a process whose start an
  earlier pass read; the map grows with the tree, as `by_guid` does. Starts are read before the `after_record` cut.
- C-3 `initiated` is null for an Initiated that is neither true nor false (any case), as for a missing one.

  fires (an ssh started by git whose start the follow does not hold is not left out: a false positive, never a

## The command of the eight rewritten fixtures (added by the Table, review F13)
Run from the repository's root with the commit before the task as its argument's base (2f2bcb0):

```python
import json, subprocess, sys
FOUR = ("initiated", "dest_scope", "image", "parent_image")
def strip(rec):
    if isinstance(rec, dict) and rec.get("tool") == "net" and isinstance(rec.get("input_meta"), dict):
        for k in FOUR:
            rec["input_meta"].pop(k)
    return rec
paths = subprocess.run(["git", "diff", "--cached", "--name-only", "2f2bcb0", "--", "tests/fixtures"],
                       capture_output=True, text=True, check=True).stdout.split()
changed = [p for p in paths if not p.startswith(("tests/fixtures/rules/PERSIST-AUTOSTART/", "tests/fixtures/rules/NET-ADMIN-PORT/"))]
for p in changed:
    old = subprocess.run(["git", "show", "2f2bcb0:" + p], capture_output=True, text=True, check=True).stdout
    new = open(p, encoding="ascii").read()
    if p.endswith(".json"):
        doc = json.loads(new); doc["lines"] = [strip(r) for r in doc["lines"]]
        same = json.dumps(doc, indent=1, sort_keys=True, ensure_ascii=True) + "\n" == old
    else:
        out = []
        for line in new.splitlines(True):
            try:
                rec = json.loads(line)
            except ValueError:
                out.append(line); continue
            if rec.get("tool") == "net" and rec.get("source") == "os":
                line = json.dumps(strip(rec), separators=(",", ":"), ensure_ascii=True) + "\n"
            out.append(line)
        same = "".join(out) == old
    print("same-but-the-four-keys" if same else "DIFFERS", p)
print(len(changed), "files rewritten")
```
