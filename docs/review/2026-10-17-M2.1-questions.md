# M2.1 review page - design questions and one scope deviation

## Scope deviation (disclosed)

`tests/test_cli.py` is outside the M2.1 scope, yet the obsolete test
function `test_commands_not_yet_available_are_usage_errors` (six lines,
by then asserting only that `review` is "not available yet") was
removed. Same cause and same reasoning as in M1.3: the builder's own
forward-looking assertion from M1.2 contradicts this task's E1, the gate
cannot be green with it, STOP is reserved for other cases, and the
product must not be shaped to satisfy a stale test. Nothing else outside
scope was touched; the commander may revert.

## Readings taken

1. **As-of for a review** is the period end, or today when the period is
   still running (`--as-of` pins it, which the tests use). A column of
   the policy board whose month is cut shows the cut date in its header.

2. **The policy board has one column per month of the period**, each the
   verdict of `check` at that month's end (cut at as-of). That is how the
   planted 2026-07 breach is visible on a 2026-Q3 page whose as-of
   verdict for WLT-01 is `hold`. A year page has twelve columns.

3. **Findings of the period** are the union of the findings of every
   monthly column, plus DECISION-DUE as of the as-of date and the loader
   problems of decisions.yml and rates.csv; exact duplicates collapse.

4. **Income vs expense per month** shows the trailing twelve months to
   as-of with the period's months marked, so a one-month page still has
   context; spending by category and allocation are strictly the period
   (allocation as of the period end). An Unknown month shows "?" and a
   stale class shows "stale" with no bar.

5. **Dark mode** uses `@media (prefers-color-scheme: dark)` guarded by
   `:root:not([data-theme="light"])`, and `:root[data-theme="dark"]`
   repeats the dark tokens so a reader can force either theme on the
   root element; no script is needed for that.

6. **The details table** lists every ledger, holdings and rate row cited
   by any verdict in any board column, once, sorted by file and line;
   rows cited only by loader problems (invalid lines) appear in the
   findings table by `file:line`, since no parsed row exists for them.

7. **`-o -` writes the page to standard output**; a missing `-o` or
   `--period` is a usage error (exit 2); an unwritable output path is
   exit 3 like an unreadable input.

8. **Geometry.** Axis ticks are real values from a 1-2-5 step chosen in
   Decimal; only the pixel projection uses float, as E4 allows; every
   printed amount is `rules.money` or `rules.pct` from Decimal.
