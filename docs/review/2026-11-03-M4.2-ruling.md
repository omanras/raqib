# M4.2 ruling (the Table, 2026-11-03) - on the STOP ed039f2 and its questions

The STOP was right. Three files outside Scope pin the rule set (S-1, S-3);
the Table's Scope was the cause (same error as M5.1 and M4.1: the grep of
exit criteria against Scope missed README.md and gate.yml, which hold the
rule count). Ledger entry recorded in ADR-0002 Amendment D.

  table note), E5 (SILENCE-EMPTY). The two demands LANDED-NO-GATE and

  or post line, no stop, and a session_end (closed). A session_end with no
  session_start in the trace is also SILENCE-EMPTY (cites the end line;
  note "no start"). A session_start alone at the end of the trace is
  SILENCE-OPEN's fact and fires SILENCE-EMPTY NOT (one fact, one finding).
  start + stop + end with no tool is not empty (SILENCE-GAP territory).
- D-7 Because of D-6 the finding is settled at the session_end line, which
  is final; watch.py's settle-at-once holds, GROWS unchanged (S-5 void).
