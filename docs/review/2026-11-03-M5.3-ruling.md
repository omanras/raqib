# M5.3 ruling (the Table, 2026-11-03) - on the STOP 4660b2a (Q-1..Q-9)

The STOP was right: CROSS-SOURCE needs a construct, and the os record shape
decides what three signatures do. Rulings = ADR-0003 Amendment C. Scope is
widened to raqib/rules/cross.py (new), tools/gate.py (kinds from cross.py),
raqib/discover.py (one shared Sysmon helper), raqib/rules/silence.py (GAP
exemption).

- C-1 (Q-1) CROSS-SOURCE is a CODE rule in raqib/rules/cross.py with
  RULE_KINDS = {"CROSS-SOURCE": "anchor"}, SEVERITY high, class CROSS
  (Q-5); report lists it beside the silence ids; the gate reads
  cross.RULE_KINDS as it reads silence's. No YAML construct.
- C-2 (Q-2) The rule judges only traces that hold os lines. With no os
  line it emits nothing and no note: the os source is opt-in and the
  report's `sources:` line already shows its absence. Linux/macOS traces
  stay CLEAN (ADR-0005 C-6 holds).
- C-3 (Q-3) Window reading B: a line is judged only when its time falls
  inside the span of the other source's records in the trace; outside the
  span it is unknown (partial note). asked-not-done: a shell pre with no os
  process within W whose program is in the pre's command_programs (or
  command_head) or is a shell image. done-not-asked: an os process whose
  program is in no shell pre within W.
- C-4 (Q-4) Shell tools: `Bash` and any tool name that, lower-cased,
  contains "bash", "shell", "execute_command", "run_command" or "cmd";
  the list is in the rule and the README. Programs are folded: lower case,
  `.exe`/`.cmd`/`.bat` stripped. done-not-asked counts only processes
  whose parent is NOT the root agent process (the agent's own helpers,
  rg/git/MCP servers, are the agent's, not acts it asked a shell for);
  named as a hole (an agent that runs its acts as direct children).
- C-5 (Q-6) os record shape: posts carry `output_meta: {}`;
  SECRET-OUTPUT and NET-TOOL add the guard `source != os` (dated note in
  each description; os net lines are a later rule); net lines carry
  `input_meta: {dest_port, dest_private}` and the sha256 of the
  destination; the os session id is `os-<root pid>` with cwd from
  `--cwd`, else event 1's CurrentDirectory of the root, else the proxy
  rule's "unknown"; SILENCE-GAP and SILENCE-ORDER skip sessions whose
  records are all `source: os` (hole named: os idle is not judged);
  reruns append and are not deduplicated (visible duplicates, A3).
- C-6 (Q-7) discover.py gains one shared helper that keeps raw
  CommandLine (hashed by os-sysmon), ProcessGuid, EventRecordID and UDP
  event 3; discover's own output is unchanged (tests pin it).
- C-7 (Q-8) Root-not-found, missing event ids, unreadable events, a
  failed wevtutil: one RAQIB-SILENCE line each; POSIX without --from is
  usage error exit 2; one run, no follow. "No event 3 in the window" is an
  INCOMPLETE-class note (exit 3), not an alarm; README says Sysmon needs
  `-n` for network events.
- C-8 (Q-9) fp_budget 0.1 until the field test; the os halves of the
  fixtures are os-sysmon --from output of synthetic XML; the rg
  false positive from the prototype is the C-4 negative fixture.
- C-9 Kinds line anchor=4; README 13 rules (WORDS 13), row; ADR-0002 note
  row + "Ratio after M5.3: 4 : 5 : 4."; THREAT_MODEL section.
- Ledger, Table: the HANDOFF named "engine.py" for a construct the
  engine does not have and put the fixture/report scope too narrow;
  rule: a new rule class names its file and the gate in Scope.
