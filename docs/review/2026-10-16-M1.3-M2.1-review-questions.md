# REDO 3, part 1: builder's response to docs/review/2026-10-16-M1.3-M2.1-review.md

## Fixed (commit `landed: REDO 3 report and suspicion layer ...`)

**M1.3**
- **3.1 [high]: a findings file is tied to its trace.**
  - `rules -o F` writes the sha256 and record count of the trace into
    `F.notes.json`.
  - `report TRACE --findings F` raises the alarm `findings-for-another-trace`
    when the sha256 differs. A trace that grew after `rules` ran counts as
    different too.
  - A findings file without its sidecar is still `incomplete`, never clean.
- **3.2: the text report runs every line through the printable filter.**
  A newline, CR or ESC in a session id or summary can no longer print a fake
  `RESULT:` line. This is tested with a forged finding.
- **3.3: cited lines show `cwd=...`.** Cut lines keep their end, with the
  middle elided (M3.1 B2).
- **3.4: a malformed notes sidecar** (notes not a list of {rule_id, status,
  detail}) is a usage error, exit 2, not a traceback.
- **Mutant `report.py:101` (raised alone):** a raised suspicion on an
  otherwise clean trace now has a test, and it gives ALARM.

**M2.1**
- **3.1 [high]: an answer from the server-side fallback is named.**
  - Each Anthropic call records `response.model`. When it differs from the
    model asked, the line carries `answered_by` and the run record counts
    `answered_by_other_model`. That count includes windows dropped below the
    threshold. `suspect` prints the count on stderr.
  - The fallback stays on, as Q4 records. It can now be seen.
- **3.2: session id and working directory moved into `<session>`.**
  - The first line of the prompt now holds only seq numbers and a count.
  - The system prompt lists `<session>` with the untrusted tags.
- **3.3: only allow-listed metadata is sent.**
  - input_meta: path, url_host, command_head. output_meta: scan,
    secret_kinds, placeholder_kinds.
  - Every string is cut to 300 characters, so planted keys and long text
    never leave.
  - A line whose cwd differs from the window's carries its own `cwd` (3.11).
- **3.4: `suspect --findings F` checks every finding** with
  `engine.check_finding`; a bad one is exit 2 with its number.
- **3.5: the suspicion run record must account for the file.** Each of these
  is an alarm (`suspicion-run`) in report and web view, never a crash:
  - a missing run record;
  - malformed keys;
  - raised or error counts that differ from the file;
  - counts that do not add up to the windows.
- **E2 reading side:** a suspicion line citing seqs outside its own window
  is rejected (A5).
- **3.7: `suspect` exit codes** are 1 when anything is raised (or the trace
  is empty or corrupt), 3 when nothing was raised but a window was not
  judged, and 0 when nothing was raised, which is not a clearance.
- **3.9:** an Ollama URL that is not localhost gives a stderr notice that
  metadata leaves the machine. So does the Anthropic backend.
- **3.10:** a non-backend failure now reads "the window could not be
  judged", not "backend failed".
- **3.12:** the unbacked `ant auth login` hint was removed.
- **Mutants:** 17 were run ad hoc and all were killed. The harness is not in
  git.
