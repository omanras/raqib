## Findings
P1 (must-fix, A3, E3) Lines handed to the suspect layer as judged were never sent. _suspect_start keeps only the
   last DEFAULT_WINDOW (40) host lines (host.py:1487) but advances suspect_upto to the file's last seq
   (host.py:1534). Probe: five remotes, 20 rounds, 120 lines: windows seq 21-60 and 81-120 sent, seq 1-20 and
   61-80 never, no hole, no note. One line per remote per round (P6) makes this the normal case.
P2 (must-fix, A3, E3) An unknown tree whose source is os (Sysmon) or hooks is never sent, and the record says
   nothing about it. Jobs keep only records with source host (host.py:1483); an os source's file holds
   source "os" lines, so the tree is skipped and the run reads "nothing new to send" (host.py:1492-1495). E3
   reads "over each UNKNOWN tree's source file"; a hooks tree sends only the host lines beside its trace.
P3 (must-fix, E3, A8: the record) "Never two calls at once" (Q-8) does not hold after a late call. suspect-late
   sets suspect_call to None and lets the thread run on (host.py:1512-1520); the next R-th round starts a
   second SuspectCall. Probe: a backend slower than the timeout, 45 rounds: 4 judge calls in flight at once.
   Ollama's own timeout is 300 s (backends.py:35), the SDK's longer: the 120 s hole does not end the call.
P4 (should-fix, E3: "hashes and names only") The tree's pid leaves the machine: the window's <session> carries
   session_id "host-<pid>" (host.py:1895; core.py:136). Also sent: ts and seq (times, not names). The
   destination is sha256 of {"destination": "ip:port"}, unsalted (host.py:741): reversible by trying candidate
   addresses, a pseudonym, not a secret. README:54 says "hashes and program names only". Table: accept, salt
   per run, or drop the pid.
P5 (should-fix, E2, Q-3/Q-5; Table) With a connection that stays up and T <= W, the rule is "a new child in K of R
   rounds", not "talk then act". Each round with the remote established is a talk beat (host.py:1614-1616,
   per the HANDOFF's "new or still established"); on Linux an act is placed at the round's own time
   (host.py:1611), so it pairs with the same round's talk and W never excludes anything; on Windows a child
   started up to 30 s after any earlier round pairs. The YAML hole "W is as coarse as the round interval"
   (HOST-RHYTHM.yaml:36) understates it; this is the IDE case Q-5 leaves unmeasured, and on Linux it is the
   whole rule.
