# M6.2 ruling (the Table, 2026-11-03) - on the STOP ebac874 (Q-1..Q-12)

The STOP was right (Scope omitted cli.py for an option named in E1; the
Table's grep rule missed "--refresh"). Rulings = ADR-0005 Amendment I.

- I-1 (Q-1) raqib/cli.py joins Scope for `--refresh N` on `watch` and on
  `ui --serve` (one page builder), its pass-through and usage lines. N is a
  whole number 1..3600; anything else is a usage error (exit 2).
- I-2 (Q-2) AGENT GONE: the newest record is a session_end and no line has
  come since. It wins over SILENT: after a session_end no silence window
  opens until the next line; a window open at that moment closes on the
  end line (an end is a line). The next session_start returns WATCHING.
- I-3 (Q-3) CAPTURE FAILED holds while the newest line is a RAQIB-SILENCE
  marker or the hooks are missing/foreign at start (doctor's check,
  read-only); the next good line clears it and the band's detail says
  "recovered at seq N". Order: CAPTURE FAILED > SILENT > AGENT GONE >
  WATCHING; FINISHED when watch ended (final page). One state word plus a
  detail line (C-4 crashed texts live in the detail).
- I-4 (Q-4) The page is built from the dict watch holds in memory; the
  file is for other readers. A watch.json that cannot be written is a hole
  in the band. Other watches are read from the registry on disk, and the
  page says the registry is same-user writable (forgeable).
- I-5 (Q-5) The registry write is serve wiring (watch.py). GONE rows are
  never pruned by Raqib (A3); the person deletes the file. Lock: O_EXCL
  lock file, broken after 10 s with a note in the row. A corrupt registry
  is left as it is and shown as a hole; the page always shows its own
  watch from memory.
- I-6 (Q-6) Windows liveness by ctypes OpenProcess + GetExitCodeProcess
  (never a signal, A4); POSIX os.kill(pid, 0). ALIVE requires pid alive AND
  a heartbeat younger than 3 heartbeat intervals; otherwise GONE with the
  reason (pid, heartbeat, or both). Pid reuse is a named hole.
- I-7 (Q-7) Links only from a whole-number port 1..65535 as
  `http://127.0.0.1:<port>/`; no other host.
- I-8 (Q-8) `GET /discover` on the same server, same headers and refresh,
  shows the file's age; an unreadable or malformed discover.json is an
  alarm on the tab (A3). In static `raqib ui` the tab appears only when
  the file exists next to the trace.
- I-9 (Q-9, Q-10) One page builder for `raqib ui` and watch: band (watch
  only) -> alarms (capture holes, A3 first) -> findings grouped high >
  medium > low, empty groups hidden, unknown severity in "other" last with
  a note -> timeline. Amendment A-6's byte-for-byte rule is retired by a
  dated note; the test updates.
- I-10 (Q-11) Closed live windows are drawn too (lighter), open ones marked.
- I-11 (Q-12) Control characters keep being replaced by "?" (A5).
- I-12 D-8 applies: every behaviour tested, hostile strings included.
