    - *Windows:* CHANGELOG.md:28 and GUIDE.md:22 say `py -m pip install --upgrade .`. README.md:68 gives `pipx install

    for an update, `sudo cp -r CHECKOUT DIR/src` onto an existing DIR/src copies into DIR/src/<name>, so `sudo
    DIR/bin/pip install DIR/src` reinstalls the old code. No step restarts the unit.
    - *Both:* no step says to restart a running watch, window or service. A running one keeps saying the old number,
    which is the confusion in ADR-0015's Context.
