== Q1-Q10 (safe as built, and the cost) ==

- Q1 (head reach/rehash): safe. Cost: the head is re-read (<=4096 bytes) each time the cursor passes more of the first
  4096; a change after the passed head-region and before the cursor line is unseen (K-2 blind spot).
- Q2 (older state has no head -> trust at first sight): safe. Cost: a file swapped while the forwarder was down,
  before the first look, is judged by the cursor line only (as before N) — the cursor-0 identity check does not
  protect a pre-N state's first look.
- Q3 (100/50 oscillation): safe, bounded, no loss beyond documented at-least-once. Cost: one try in two is late (a
  100-line send abandoned at the bound; partial bytes at the collector; lines of the overlap may arrive twice).
  Confirmed by test 1662.
- Q4 (refusing stays while in question, converts at the take): this is the open question behind Finding 1. "Safe" for
  exit code and for status (N-5's in_question is authoritative), but a state with a line in question can carry
  failing=None or another word (late/connect) rather than `refusing`, so the literal E2 wording is not met; the test
  tolerates it. The Table must rule.
- Q5 (in_question.since resets across a restart): safe. Cost: `since` after a restart times from the restarted run's
  first refusal, not the first run's; failing.since (carried, M-6) still carries the true duration; status can read 0
  for up to a beat after a restart for a line that had waited long.
- Q6 (behind bounded, no Stop poll): safe — see Focus 6; <=17 reads. Cost: past a >1 MiB no-newline tail, `behind` is
  a lower bound, so status under-reports the bytes-behind until the walk reaches them (documented).
- Q7 (the walks N-8 does not name): safe. Cost: `--from end` hashes the last whole line once at resume with no Stop (a
  Stop there would leave a first run with no end cursor); read_lines parses one <=512 KiB chunk of possibly many tiny
  lines at once, with Stop/beat checked between lines, not inside the parse (bounded by 512 KiB).
- Q8 (pid nobody has -> rewrite; life-cannot-be-told -> exit 1): safe and matches FORWARD.md/THREAT_MODEL. Cost: a
  transient unreadable pid (holder False) is tolerated at a write but refused at the start — a mild asymmetry,
  documented.
- Q9 (every run on its own thread; signals on the main thread): safe. Cost: a run reached through cli.main on a
  non-main thread installs no signal handlers (cli_run:1772 guards on main_thread); the real-signal path is covered
  only by the subprocess test (1223). The flag is still polled by stopped().
- Q10 (201-request bound): safe, bounded, no livelock (Focus 7). Cost: latency only; lowering is the Table's call, not
  required for correctness.
