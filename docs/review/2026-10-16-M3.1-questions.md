# M3.1 read-only web view: questions and assumptions

Task: HANDOFF.md (M3.1). Built:
- `raqib/ui.py`;
- `python -m raqib ui TRACE [-o FILE | --serve [--port N]]`, which takes
  the same rule, findings and suspicion options as `report`;
- `tests/test_ui.py`.

The page was looked at in headless Chromium, at 1280 px and, inside a
390 px frame, at phone width. These were three pages: the real blocked-calls
trace, the real file-tools trace, and a hostile trace. The screenshots are
not in git.

## Open questions (not answered)

- **Q1 One trace per page.** The view covers a single trace file, where the
  plan says "timeline, findings, silence windows". Is a view across traces
  or sessions wanted for v0.1?
- **Q2 Is serving needed at all?** `-o FILE` already gives a page that can
  be opened from disk. `--serve` adds a localhost listener that anyone on the
  machine can read, the watched agent included. It is read-only, but the
  agent could learn what the watcher reports. Should `--serve` be dropped
  (A4)?
- **Q3 Default port 8765.** It is arbitrary. `--port 0` picks any free port.

## Assumptions made (confirm or overrule)

- **The page reuses `report.build`.** Result, alarms, findings, notes and
  rule table mean the same as in `raqib report`, and the exit codes are the
  same (0, 1, 3).
- **Silence bands are computed in the view** from the same `gap_seconds` as
  the rules. They cover a gap, an unclosed session and a corrupt line. A
  pre without a post (and a post without a pre) is a mark on the row. ORDER
  findings show only as marks from their findings.
- **Rows are marked by seq.** A finding that cites seq N marks both the pre
  and the post line of N, because citations name seqs, not lines (M1.1
  review A5-3).
- **Values are cut** to 400 characters with `...` in the middle, so the end
  of a long path stays visible (M1.1 SU1).
- **Safety:**
  - CSP `default-src 'none'; style-src 'unsafe-inline'`; there are no
    scripts, images, forms or external links;
  - every value is HTML-escaped and stripped of non-printable characters,
    which includes bidi controls;
  - `--serve` sends the same CSP, `nosniff`, `no-referrer` and `no-store`,
    and refuses any Host that is not 127.0.0.1 or localhost (against DNS
    rebinding).

## Not verified

- **Real browsers other than headless Chromium.** The page uses only basic
  HTML and CSS. Dark mode follows the system setting; it was not looked at.
- **Mutants:** 10 UI mutants were run ad hoc and all were killed (escaping,
  printable filter, Host check, 405, open band, gap band, no-post mark,
  bind address, CSP header, path check). The harness is not in git.
