## The builder's decisions

1. **Where the install's numbers are held - kept.** The reason checks out: test_wininstall.py:821 holds that
  wininstall is imported only in cli's `cmd_service`, and test_winmanager.py:503-509 holds status's one import. The
  tie also pins the literal numbers, which is stricter than asked.
2. **The method names (`actions`, `flag`, `delayed`) - kept.** `System.flag` and `api.flag` (the structure) are
  different objects, so nothing collides.
3. **NOT KNOWN for a service without the mark too - as ruled.** Z-1 says a level that cannot be read is NOT KNOWN "as
  for every other call (V-3)", and Z-2's MUST NOT TOUCH is about judging, not reading. The caller loses only the
  RESULT's words that the service is not Raqib's, and its state. The exit (3) is the same, and the mark's line is
  still written above. The Table may add "where every call was read" to SERVICE.md's NOT INSTALLED BY RAQIB row.
4. **The bound of 64 and the array placed inside the bytes - kept.** E1 implies the placing ("inside the buffer"). The
  placing does accept an array lying over the structure's own bytes, and it does not check alignment (see Silent
  assumptions).
5. **The texts said, not judged - I would rule them a difference.** As built follows Z-2's words, which do not name
  the texts. But "as installed" is exact everywhere else: the command is matched whole, and on Linux the file's whole
  text must match. The install writes no text on a service it alone made, so a text that is there means the settings
  were changed after the install. I would have it said as a difference, "<the text's line>; the install writes none".
  It is deterministic and cheap. It is inert under three starts-again today, which is why this is a ruling and not a
  fault. The change would alter test_z2_a_service_the_install_made... (tests/test_winmanager.py:880).
6. **The words - kept.** Judging a BOOL by 0 or not 0 is what Win32 BOOL means. "Never forgotten" is the documented
  meaning of INFINITE for dwResetPeriod. Keeping "exit" out of the flag's line is sound, since the exit tests hold
  every line that holds "exit" (tests/test_winmanager.py:231).
7. **The start's difference among the making's, in line order - kept.** The differences follow the order of the lines.
