  its own working directory (proxy.py:656-657, Amendment A builder note).
  A literal cwd "unknown" cannot be placed, so SCOPE-CWD-MOVED would be
  partial on every such session. Read as os-sysmon's own working
  directory.

  engine.CLASSES. CLASSES gains CROSS in raqib/rules/engine.py, under
  HANDOFF Scope `raqib/rules/` (the first M5.3 Scope named engine.py, and
  the ruling widened Scope).
- C-4 "parent is NOT the root agent process": os process lines carry
  `input_meta.depth` (0 the root, 1 its children). The root itself is not
  judged either: it is the agent, not an act.
- C-3:
  - The span is first to last ts of the other side's records (all lines of
    that source).
  - A pre with unknown programs is a finding only when no os process at
    all starts in W, matched by a shell image, else unknown.
  - An os process or pre whose name cannot be read is unknown.
  - Shell images: bash, sh, zsh, dash, ksh, fish, cmd, powershell, pwsh.
  - Windows: asked [t, t+W], done [t-W, t], both ends inclusive.

  169.254/16, 100.64/10, ::1, fc00::/7, fe80::/10. A documentation address
