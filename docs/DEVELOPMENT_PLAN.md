# Mizan development plan

One micro-task per HANDOFF. The prepared handoffs live in `docs/handoffs/`;
`tools/next-task.sh` advances `HANDOFF.md` after a `landed:` commit. The
builder works on branch `claude/mizan-v0.1`, one commit per task; the
commander merges into `mizan`.

## Phase 0 — the engine
- **M0.1** loader: read a Sigma rule file, validate the shape of ADR §3,
  return a Rule or named problems. Tests with valid and invalid files.
- **M0.2** matcher: one selection against one event (ADR §5): mapping and
  keyword selections, wildcards, case-insensitivity, nested fields, every
  listed modifier, `unknown` on any other modifier.
- **M0.3** condition: parser and evaluator for the grammar of ADR §5,
  including `1 of`/`all of` with patterns and `them`; `unknown` on
  aggregations and `near`.

## Phase 1 — the gate
- **M1.1** fixtures + `test` + `match` commands: sidecar discovery, status
  per rule with `<file>:<line>` citations, text and JSON output, exit codes.
- **M1.2** corpus + budget + `corpus` command; `check` command = fixtures +
  budget over a rule directory; `--json`.
- **M1.3** example rule set: ten synthetic rules across three logsources
  (windows/process_creation, linux/auth, webserver), each with positive and
  negative fixtures; three corpus files (>= 1,000 synthetic benign events
  each, generated by a committed script with a fixed seed); `tools/gate.sh`
  runs `python3 -m mizan check rules/` so the repo gates itself.

## Phase 2 — leaving the shell
- **M2.1** export via pySigma (optional dependency, `mizan/export.py` only;
  gate checks that no other module imports `sigma`); `export` command with
  a clear error when pySigma is absent.
- **M2.2** README quickstart proven from a fresh clone; `docs/THREAT_MODEL.md`
  (how a rule author or an attacker fools the gate: fixtures that only test
  the happy path, corpora that are too clean, wildcards that match
  everything, evasions the rule does not cover); CI workflow file that runs
  the gate on push.
- **M2.3** outside reader: one person outside the project runs the quickstart
  and files one issue. Open until it happens.

## Exit of v0.1
Phases 0-2 landed except M2.3; gate green; `python3 -m mizan check rules/`
green on the example set with every rule within budget; one independent
review packet in `docs/review/`.
