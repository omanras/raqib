# HANDOFF — M1.3  (phase 1: the example household and self-gate)

Task: ship a synthetic household in examples/, generated by a committed
script, and make the repository gate itself on its planned verdicts.

Scope:
  tools/make_example.py
  examples/
  qayd/cli.py
  tests/test_example.py
  docs/review/

Exit criteria:
- E1 `tools/make_example.py` (fixed seed 20261017) writes examples/
     policies.yml (base OMR, 8 policies: 2 cap, 1 floor, 2 routine,
     1 red_line, 1 kill, 1 allocation), ledger.csv (24 months, 2024-10 to
     2026-09, salary + typical expenses + monthly savings transfer + a
     small broker pilot), holdings.csv (monthly snapshots), decisions.yml
     (4 decisions), rates.csv (USD rows). Synthetic names only.
- E2 Planted facts, documented in examples/README.md: one cap breached in
     2026-07; the kill crossed in 2025-11 and closed by a decision dated
     2025-12-05; one routine missing in 2026-03; one decision due at
     2026-09-30. Everything else holds.
- E3 `python3 -m qayd check --dir examples/ --as-of 2026-09-30` prints
     exactly the planned verdict set (reds: the due decision; the 2026-07
     breach and 2026-03 missing appear only when --as-of is in those
     periods; the kill shows closed).
- E4 `python3 -m qayd init [--dir DIR]` copies examples/ into DIR (refuses
     to overwrite existing files).
- E5 tests/test_example.py regenerates with the script and compares byte
     for byte, then asserts E3 through `qayd.cli.main`. Gate green.

Not in scope: engine changes (write a questions file if one is needed).
Commit: `landed: M1.3 example household` or `STOP: M1.3 <reason>`.
Read HANDOFF.md and do only the task it specifies.
