# Qayd Web

The browser app of Qayd: personal finance as code, with no server. Your
policies, ledger, holdings and decisions stay in your browser and in the
files you export; the engine gives deterministic verdicts and a period
review. One HTML file, works offline, never advises, never moves money,
never connects to anything. The reference engine is the Python CLI on
branch `qayd`; this app must agree with it byte for byte on the sample.

Status: v0.1 under construction on branch `qayd-web` of this repository.
See `docs/DEVELOPMENT_PLAN.md`.
