# Qayd

Personal finance as code. Declare your money policies in YAML, keep your
ledger in CSV, and get deterministic verdicts: which policy holds, which is
breached, which routine was skipped, which pilot must be killed, which
decision is due for review. Offline, stdlib + PyYAML. It never advises,
never moves money and never connects to anything.

Status: v0.1 under construction on branch `qayd` of this repository
(branches `main` and `mizan` are other projects). See
`docs/DEVELOPMENT_PLAN.md`.
