Exit criteria:
- E1 (AE-1) `raqib service run`: on Windows, the control dispatcher in a second thread and the watch in the main thread by `cli.main(["watch", "--host", "--no-page", "--no-notify"], out)`; RUNNING is reported before the watch is started; where the dispatcher says the process was not started by the service manager (error 1063) it says so on the error stream, starts no watch, exit 2; not on Windows: one line that this command is Windows', exit 2. The standard library only; ctypes is imported inside the object that holds the system's calls, never at the module's import; nothing runs at import; no program is started (tests/test_own_env.py's scan still finds its seven starts).
- E2 (AE-2) The place, `Raqib` under the environment's ProgramData (refused where that name is absent or no absolute path): each case of AE-2 as a function of what the system's object reads - absent (made, closed, read back); a link (refused); an owner that is neither the system (SY) nor the administrators (BA) (refused); open and not empty (refused); open and empty (closed, read back); closed and owned right (taken as it is). The closed list is one constant, `D:PAI(A;OICI;FA;;;SY)(A;OICI;FA;;;BA)`; after every road the list read back equals it and the owner is SY or BA, or no watch starts. Then HOME and USERPROFILE of the process are the place. A test for every case with a stand-in system, and for a read back that differs.
- E3 (AE-3) The text file: in the place, begun anew at each start, the one before kept once, bounded by one constant; past the bound nothing more is written and its last line says so, once. `sys.stdout` or `sys.stderr` that is None is replaced by it for the process; a test runs the runner's road with both None and a stand-in watch that prints and writes to the error stream.
- E4 (AE-4) Stop and Shutdown: STOP_PENDING, the interrupt, the watch's end, STOPPED - in that order (a test holds the order of the statuses with a stand-in system and a stand-in watch that ends on the interrupt). The watch's result 0, 1 or 3: exit 0 to the system. Each refusal and a watch that ended without being asked: the system's service-specific exit with a number of its own; the numbers are constants, listed in SERVICE.md with their words.
- E5 Tests run on every system of the gate with stand-ins (no test needs Windows, a service manager or ProgramData); one test, skipped off Windows, reads a scratch folder's owner and list through the real object and closes it (a folder of the test's own under the test's temp folder, never ProgramData).
