- E2 (CC-1) A child's line names every program its process ran in the round (`command_programs` in order, `command_sources` beside them). A process the watch wrote a line for that runs a program not yet said, in a later round, gets a line for that program; a program already said is not said again. Tests: `bash` then `curl` in one pid in one round: one line naming both, NET-TOOL fires; `bash` in round 2 and `wget` in the same pid in round 4: a line each round, NET-TOOL at round 4; the same program again: no line.
- E3 (CC-2) Where the name the kernel gave differs from the file's name, the line names both, each through the name gate (`plain_program`); a name of 15 characters is not used. - E4 (CC-3, CC-4) The watch keeps per tree the children it wrote and has not heard end, by pid and start (at most 512 a tree; passing it is said in the section and is a hole of the result). Tests: the parent given in round 2 and ended before round 3's sample, its child heard in round 3; a child of a kept child two rounds later; a pid reused under one tree; the bound.
