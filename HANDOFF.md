# HANDOFF — M12.4c2b2c  (ADR-0013 Amendment Z: `raqib service status` on Windows reads the start-again settings the install makes)

Task: since 0.16.0 `raqib service install` makes Raqib's Windows service with an automatic start and tells the system to start it again after an end that was no Stop; `raqib service status` reads none of that, so a service that lost those settings reads ACTIVE. Amendment Z (the end of docs/specs/ADR-0013-the-service-under-the-system.md) rules what status reads more and what "as installed" then means. Read Amendment Z whole and Amendment X's first paragraph (what was measured), then raqib/winmanager.py whole (the reader, `room`, `_said`, `_making`, `_read`, `status`), raqib/wininstall.py (its constants AUTO_START, DELAYS, RESET_PERIOD, RESTART and its structures of the failure actions: NOT to change), tests/test_winmanager.py whole (the stand-in `Manager`, the made-up `Library` and `real_with`, DECLARED, STRUCTURES), tests/test_wininstall.py (only its stand-in's `description`/`making`/`state`, which answer for the reader), tests/test_rig_check.py (`status_lines`, X53), docs/specs/SERVICE.md ("Windows: the status").

Scope:
  raqib/winmanager.py, tests/test_winmanager.py, tests/test_wininstall.py and tests/test_rig_check.py (ONLY their stand-ins of the reader, so that they answer the new calls as a service the install made; no assertion weakened), tests/test_libraries.py (only its held tables, re-printed by `dump_held()`, if a row changes), docs/specs/SERVICE.md (the status's section; the install's sentence that says status does not read them yet), docs/GUIDE.md (the status row and paragraph) with tests/test_readme_top.py where it holds them, docs/THREAT_MODEL.md (the status paragraph's sentence that says they are not read), docs/review/2026-11-27-M12.4c2b2c-questions.md.

Each returns what was read or the system's number, never raising. The count of actions read is bounded (a bound of its own) before the array is read. The structures are held field by field in tests/test_winmanager.py's STRUCTURES; DECLARED is unchanged or says why not; the made-up `Library` answers the three levels and a test runs the real object's own logic against it (the array read, a NULL array with a count of 0, a count over the bound).
- E2 (Z-1, the lines) After the account's line and before the state's: one line of what the system does after an end that was no Stop (each action as its kind's word - 0 nothing, 1 start it again, 2 restart the machine, 3 run a command, any other by its number - and its seconds; the reset period; "none" where the count is 0), one of the flag, one of the delayed start.
