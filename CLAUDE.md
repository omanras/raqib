# QAYD — read this first, every session

Qayd is personal finance as code. A household declares its money policies
in YAML, keeps its ledger in CSV, and gets deterministic verdicts: which
policy holds, which is breached, which routine was skipped, which pilot must
be killed. It never moves money and never connects to anything. It is
public, offline, and lives on branch `qayd` of this repository; branches
`main` (Raqib) and `mizan` are other projects and are never touched.

## Non-negotiable rules
1. Read `HANDOFF.md` and do ONLY the task it specifies. Touch only the paths
   listed under `Scope:`. Anything else is out of scope -> STOP.
2. One micro-task per commit. Every commit message starts with `landed:` or
   `STOP:`. Never leave the tree dirty.
3. Deterministic only. No model, no heuristic, no advice. A policy either
   holds or it does not, and the answer is the same on every run.
4. Money is Decimal, never float. Every amount carries a currency; the base
   currency is declared, conversions come from a declared rates table or the
   verdict is `unknown`.
5. Silence is red. A period with no ledger rows, a routine with no entry, a
   decision past its review date: findings, never "nothing happened".
6. No network anywhere. No bank, broker or price feed. Examples are synthetic.
7. Design questions go to `docs/review/<date>-<task>-questions.md` with the
   most conservative reading taken; keep `HANDOFF.md` <= 40 lines; ASCII in
   code, any script in docs.

## Layout
- `qayd/`      the package: ledger, policies, periods, rules, decisions,
               report, review (HTML), cli (stdlib + PyYAML only)
- `examples/`  a synthetic household: policies.yml, ledger.csv,
               holdings.csv, decisions.yml, generated by tools/make_example.py
- `docs/`      CONSTITUTION, DEVELOPMENT_PLAN, SESSION_PROTOCOL, specs/,
               handoffs/, review/
- `tools/`     gate.sh, next-task.sh, make_example.py
- `tests/`     every rule type has a test with a holding and a breaching case

## Exit of every task
`tools/gate.sh` must be green. If it is not, the task is not landed.
